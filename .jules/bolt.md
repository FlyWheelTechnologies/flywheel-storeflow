## 2025-05-18 - Single-Pass Aggregation for Multi-Series Chart Calculations
**Learning:** In dashboard components computing time-series trends (such as 7D/30D rolling windows and YoY month-by-month trends), iterating through the full dataset within each interval slot turns an O(N) operation into O(k * N). For 30-day windows or 12-month comparisons across sales and expenses, pre-bucketing items into a hash map or fixed-size bucket array (e.g. `new Array(12).fill(0)`) reduces computation to a single O(N + M) pass, achieving a >20x speedup in chart data generation without UI changes.
**Action:** When calculating grouped metrics for charts or timeframes in React hooks, always prefer a single pre-aggregation pass into a Map or fixed index array before mapping over target display intervals.
